# Metric Architectural Template

The metric template is generated locally by Inventaur_RhinoStandards_Install.py using the Rhino installation on the user's workstation.

The verified template baseline is:

- 44 architectural layers.
- 14 persistent annotation/text styles.
- 59 native Rhino hatch definitions (where supported by the installed Rhino version).
- Zero geometry objects.
- Current layer: 04_ARCHITECTURE::GENERAL.
- Current dimension style: INV_STD_MM.
- Model and page units: millimetres.

The 3DM template and its rollback copy are not redistributed in this repository. The installer generates the template on first run and validates/reuses it on later launches.
